# 银河终端项目

<br />

### 项目描述

技术栈需要性能优先，帮我选择你最熟悉的性能框架。设计风格 以 银河像素风 为主题。多个agent 支持 如同 银河中的星星一般闪耀。

参考项目<https://otty.sh/>

## **功能概览**

### **终端与标签**

| **能力**   | **说明**                                                                                                 |
| :------- | :----------------------------------------------------------------------------------------------------- |
| 全局多标签    | 顶部标签展示已加载会话；切换跨项目标签时同步当前项目上下文                                                                          |
| 标签操作     | 重命名、关闭其他、横向滚动、`Ctrl+W` 关闭；支持拖拽重排（写 `sortOrder`）                                                        |
| 动态标题     | 捕获 OSC 0 标题，取 basename 简化显示；无内容时回退「终端 N」                                                               |
| Agent 标记 | 运行 Claude Code / Codex / OpenCode / OMP / Grok / Crush 时，标签与侧栏显示对应徽章                                   |
| 命令块      | 按回车边界把命令与输出成块；支持复制命令/输出、重跑、收藏                                                                          |
| 搜索       | `Ctrl+F` 跨 pane 终端查找；`Ctrl+Shift+F` 命令块搜索；`Ctrl+R` 统一命令搜索                                              |
| 字体       | Cascadia Mono + 微软雅黑 UI 等宽组合，中英文对齐优化                                                                   |
| GPU 渲染   | xterm WebGL 渲染器（文本/单元格批量上 GPU），高吞吐输出更流畅、CPU 更省；WebGL 不可用 / 上下文丢失自动回退内置 DOM 渲染器（借鉴 Ghostty / OrcaShell） |
| 高吞吐数据通路  | 主进程把同一事件循环内的 PTY 输出合并为单次 IPC，降低序列化与渲染唤醒开销（交互输入零延迟）                                                     |
| 活动脉冲     | 标签呼吸小圆点指示正在输出的终端，一眼分辨哪些 shell / agent 在忙（借鉴 OrcaShell）                                                 |

### **分屏与布局**

| **能力** | **说明**                                                       |
| :----- | :----------------------------------------------------------- |
| 分屏     | `LayoutTree` 驱动：向右 / 向下分屏，命名布局切换                             |
| 快捷键    | `Alt+方向键` 切换 pane；`Alt+Shift+方向键` 调尺寸；`Ctrl+Shift+W` 关闭 pane |
| 布局记忆   | 分屏权重树 `layoutSnapshot` 优先于 `layoutName`；重启后按比例还原             |
| 布局模板   | 设置中心可保存 / 应用布局模板                                             |
| 同步输入   | 向当前会话全部 pane 同步写入                                            |
| 跨标签移动  | 将 pane 移到其它会话标签                                              |

### **Agent**

| **能力** | **说明**                                                  |
| :----- | :------------------------------------------------------ |
| 历史面板   | 右侧面板列出当前项目相关 Agent 会话，可查看消息流并一键恢复                       |
| 恢复注入   | 新建终端后向 PTY 写入 resume 命令（如 `claude --resume <id>`）       |
| 状态检测   | 启发式解析输出尾部：`idle` / `working` / `blocked`；PTY 退出标 `done` |
| 通知     | Agent 完成或阻塞时可发系统通知；状态栏通知中心可查看 / 全部已读                    |

#### **Agent 支持矩阵（Windows 实测路径）**

| **Agent**   | **存储**                                                                              | **项目匹配**                                | **恢复命令**               |
| :---------- | :---------------------------------------------------------------------------------- | :-------------------------------------- | :--------------------- |
| Claude Code | `~/.claude/projects/<sanitized-cwd>/<uuid>.jsonl`                                   | 行内 `cwd`                                | `claude --resume <id>` |
| Codex CLI   | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`                                      | `session_meta` / `turn_context` 的 `cwd` | `codex resume <id>`    |
| OpenCode    | `~/.local/share/opencode/opencode.db`（SQLite）                                       | `session.directory`                     | `opencode -s <id>`     |
| OMP         | `~/.omp/agent/sessions/<sanitized-cwd>/<timestamp>_<uuid>.jsonl`                    | `session.cwd`                           | `omp -r <uuid>`        |
| Grok Build  | `~/.grok/sessions/<url-encoded-cwd>/<uuid>/`（`summary.json` + `chat_history.jsonl`） | `summary.info.cwd`                      | `grok -r <uuid>`       |
| Crush       | `<project>/.crush/crush.db`（SQLite，按项目存储）                                           | 项目内 `.crush`（天然按项目）                     | `crush --session <id>` |

> OpenCode 依赖 Node 实验性 `node:sqlite`（Node 22.5+）。不可用时该列表为空，不影响其它 Agent。

### **项目与会话**

| **能力**         | **说明**                                                              |
| :------------- | :------------------------------------------------------------------ |
| 项目管理           | 会话归属项目；顶部标签可跨项目浏览；侧栏 / Git / 新建终端跟随当前项目                             |
| 持久化            | 项目与会话 → `userData/store.json`；命令块 → `userData/blocks.jsonl`（上限 500） |
| 会话恢复           | 重启后加载已持久化会话并重新 spawn PTY；带 `agentKind` 的会话会重注 resume 命令             |
| 右键打开           | 资源管理器「在此处打开星轨终端」（目录 / 背景 / 驱动器）；`--open-here` 单例转发                  |
| Shell Profiles | 自动探测 PowerShell / pwsh / cmd / Git Bash / WSL；支持自定义 profile         |

### **Git**

* 右侧 Git 面板：分支、ahead/behind、变更计数与文件列表

* 状态栏分支下拉：直接 checkout

### **界面与配置**

| **能力**    | **说明**                                                 |
| :-------- | :----------------------------------------------------- |
| 自定义标题栏    | 可拖拽；最小化 / 最大化 / 关闭；显示应用名与当前项目                          |
| 深色 UI     | 界面强制深色（`nativeTheme.themeSource = 'dark'`）；设置中心仅保留深色选项 |
| 设置中心      | 通用 / Workflows / 布局模板 / 触发器 / 快捷键                      |
| 通用项       | 终端/界面字号、语言（中/英）、默认 profile、全局热键、右键菜单、Agent 通知、状态栏组件    |
| Workflows | 参数化命令模板（`{{param}}` 占位，运行时填参）                          |
| 触发器       | 正则匹配输出 → 通知 / 标记 / 响铃 / 停止滚动                           |
| 快捷键       | 可查看、改写、禁用、重置                                           |
| 命令面板      | `Ctrl+P`：新建终端、添加项目、打开面板、Workflows / 触发器 / 布局等入口        |
| 诊断        | 版本 / OS / shell / 配置路径 / PTY 后端 / 功能开关，可复制报告           |
| 单例        | 仅允许一个实例；二次启动聚焦已有窗口并转发 `--open-here`                    |
| 窗口记忆      | `config.windowState` 记住位置、尺寸、最大化                       |
| GPU       | 默认硬件加速；`CAPTURE_SCREEN` 截图模式降级软件渲染                     |

### **状态栏组件**

可配置显示与顺序：`git` · `cwd` · `sessions` · `agent` · `notifications` · `clock`
