# 隐私说明（§9.3 发布物）

## 数据去向

银河终端默认**不向外发送任何数据**。除以下两条用户主动触发的网络行为外，不发起网络请求：

1. **自动更新检查**（可禁用）：连接更新端点下载签名清单与安装包。不包含设备标识、不包含项目/会话内容。
2. **外部链接**：你在终端中点击链接或调用“打开链接/路径”命令时，由系统默认浏览器处理，应用不经手中转。

## 本地数据

全部数据保存在本机数据目录（诊断页可见路径，Windows 为 `%APPDATA%\com.galaxyterminal.app`）：

| 文件 | 内容 |
| --- | --- |
| `store.json` | 项目、会话、布局、设置、窗口状态 |
| `blocks.jsonl` | 命令块（命令与输出文本），非收藏块上限 500，超量自动淘汰最旧的非收藏块 |
| `backups/` | 最近一次有效 `store.json` 备份 |
| `logs/` | 滚动应用日志。**默认脱敏**：用户主目录路径以 `~` 代替，用户名以 `<user>` 代替；命令参数与终端内容不写入日志 |
| `run_state.json` | 干净退出标记（崩溃恢复用） |

**Agent 历史（Claude Code / Codex / OpenCode / OMP / Grok / Crush）始终以只读方式访问**，应用不会修改、删除或上传任何 Agent 自有数据；Agent 恢复命令仅由适配器按规则生成，不执行历史文件中的命令字段。

## 诊断包

“设置 → 诊断 → 生成脱敏报告”是你主导的行为。报告仅包含版本、OS 描述、PTY 后端、配置/数据/日志路径（已脱敏）、Shell 列表、功能开关，**不包含**终端内容、命令块输出、命令参数或任何 Agent 会话内容。生成前你可以预览完整内容。

## 崩溃与遥测

应用不包含崩溃上报与遥测组件。崩溃恢复数据仅保留在本地。

## 第三方组件

第三方组件及其许可见 `docs/THIRD_PARTY_LICENSES.md`。组件均以静态链接/打包形式分发，不在运行时回传数据。
