# 主题与导航修正设计

## 背景

上一轮工作区洞察重设计已经切换了主色，但终端 xterm 主题、旧 CSS 选择态和设置章节仍保留旧紫色宇宙视觉。左侧导航还暴露了重复入口：项目与会话都只是打开同一个上下文栏，收藏入口实际打开命令搜索。

## 目标

- 终端背景、前景、光标、选区与 ANSI 调色板和工作区主题保持一致。
- 清除标题栏、标签、项目项、设置导航中的紫色渐变、紫色边框、发光和星点动画。
- 将旧版本保存的默认紫色项目标记精确迁移为信号绿，不覆盖其他自定义颜色。
- 将主导航收敛为终端、洞察、命令历史三个工作流，设置固定在底部。
- 设置页章节目录在桌面保持窄列，窄屏改为可横向滚动的顶部目录。
- 不改变 PTY、洞察聚合、右侧 Agent/Git/历史/通知面板；存储仅增加兼容的 v3→v4 颜色迁移。

## 交互决策

主导航的“终端”负责进入终端工作区；“洞察”负责统计画布；“命令历史”打开现有命令块搜索。项目与会话只在终端上下文栏中切换，避免两个按钮表达同一动作。设置章节按钮使用 `aria-current`，键盘焦点保持可见。

## 主题决策

xterm 调色板作为终端颜色的唯一来源，终端宿主直接复用其背景色；背景、前景、光标、选区与 ANSI 色全部使用炭黑、冷白、青绿色和状态色。紫色不得出现在通用界面 chrome。

## 验证

- 单元测试验证导出的 xterm 主题和导航入口数量/行为。
- Playwright 验证终端与设置页在桌面、800px 和 560px 宽度下无溢出。
- 运行 `npm test -- --run`、`npx tsc --noEmit`、`npm run build` 和 UI E2E。
