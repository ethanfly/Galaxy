# Galaxy Terminal 原始 PNG 圆角品牌设计

## 目标

恢复提交 `56ee171` 中的 `src-tauri/icons/logo-master.png` 作为 Galaxy Terminal 唯一品牌源图，并将用户确认的 25% 大圆角应用到所有品牌展示和发行产物。功能图标、黑白界面主题及其他视觉元素保持不变。

## 源资产

- 唯一源图：历史提交中的 1024×1024 `logo-master.png`。
- 保留原图的白色笔触 G、黑色背景、构图比例和光晕质感。
- 输出时使用宽高 25% 的圆角半径裁切，圆角外区域必须为透明像素。
- 源图以项目内明确命名的品牌主资产保存；所有派生 PNG 和 ICO 均由生成脚本产生，不允许手工维护多个版本。

## 全局应用范围

生成链路输出并提交以下品牌资产：

- Web favicon：`public/icon.png`
- Apple touch icon：`public/apple-touch-icon.png`
- 标题栏品牌图：由标题栏引用统一的生成资产
- Tauri PNG：32×32、128×128、256×256
- Windows ICO：16、32、48、256 四档图像
- Tauri 窗口、任务栏、可执行文件和 NSIS 安装器：继续通过 `tauri.conf.json` 使用统一 ICO/PNG 产物

标题栏不得继续引用当前单色 SVG 品牌图，以免应用内与系统级图标不一致。现有功能图标仍使用 Lucide 图标系统，不在本次变更范围内。

## 生成流程

`scripts/gen-icons.mjs` 读取唯一 PNG 主图，在内存中完成正方形缩放与 25% 圆角 alpha 裁切，再输出所有尺寸。ICO 继续封装 PNG payload，确保 Windows 小尺寸和高分屏均使用同一品牌设计。

生成过程应可重复：相同源图和代码必须产生与仓库中已提交产物逐字节一致的文件。若源图缺失、尺寸不符合要求或无法解码，命令应明确失败，不回退到程序化占位 Logo。

## 验证

图标测试应验证：

- 唯一 PNG 主图存在且为 1024×1024。
- 生成 PNG 尺寸正确，四角为透明像素，圆角内侧和图案区域存在可见像素。
- ICO 包含 16、32、48、256 四档有效 PNG payload。
- 临时生成结果与仓库已提交的 Web/Tauri 图标逐字节一致。
- 标题栏只显示一个品牌标记，并引用新的统一 PNG 资产。

完成实现后运行 TypeScript、前端单元测试、图标测试、Rust 测试和完整 Tauri NSIS 打包，并检查最终安装器路径、大小和 SHA-256。

## 提交与发布

本次实现与尚未提交的全局热键修复一并经过完整验证，但提交时保持关注点清晰。用户提供的 `AGENTS.md` 不纳入版本控制。构建成功后推送当前功能分支，不提升版本号。
