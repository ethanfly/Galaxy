# Galaxy Terminal 工作台与洞察界面重设计

## 1. 文档状态

- 日期：2026-08-04
- 状态：已确认，待实施
- 分支：`feat/workspace-insights-redesign`
- 关联基础设计：`docs/superpowers/specs/2026-07-30-galaxy-terminal-design.md`

本文定义 Galaxy Terminal 新版桌面界面和洞察统计功能。未在本文修改的后端安全、PTY、持久化、Agent 只读访问和错误处理约束，继续以基础设计为准。

## 2. 目标与原则

新版界面服务于高频使用多个项目、终端和编码 Agent 的开发者。设计必须同时满足：

1. 终端仍是最高频、最低阻力的核心工作面。
2. 统计成为与终端同级的完整视图，而不是拥挤在侧栏里的装饰组件。
3. 所有统计来自 Rust 后端持有的真实持久化数据，前端只缓存和展示。
4. 视觉语言安静、精准、耐看，避免常见 AI 生成界面的紫色渐变、玻璃卡片、夸张辉光、三等分卡片和无意义动画。
5. 重新组织界面时保留现有核心工作流、快捷键、IPC 安全边界和可访问性能力。

## 3. 信息架构

应用采用“主导航轨 + 可展开上下文栏 + 工作区 + Inspector”的四层结构。

### 3.1 主导航轨

主导航轨固定宽度 56px，位于窗口左侧，包含：

- 项目
- 会话
- 洞察
- 收藏
- 设置

按钮使用项目现有 SVG 图标体系，图标按钮有工具提示和可见焦点状态。当前视图通过背景、图标色和边缘标记共同表达，不只依赖颜色。

### 3.2 上下文栏

项目或会话视图打开时，上下文栏在主导航轨右侧展开，默认宽度 220px，可折叠。它负责项目列表、项目内会话列表及其快捷操作。

洞察视图默认收起上下文栏，用页面内筛选器选择“全部项目”或具体项目，优先保留统计画布宽度。

### 3.3 顶部上下文栏

顶部栏仅保留：

- 当前项目或“全部项目”上下文
- “终端 / 洞察”分段切换
- 全局搜索入口
- Inspector、通知和设置入口
- 原生窗口控制

现有独立标签栏合并进终端工作区内部，减少连续横向工具栏造成的空间割裂。

### 3.4 工作区

工作区有两个顶级模式：

- `terminal`：会话标签、分屏终端、查找条和终端状态。
- `insights`：统计筛选器、热力图、趋势、项目排行、Agent 分布和最近活动。

模式切换不得销毁 PTY 或 xterm 实例。隐藏终端时保留现有非响应式终端注册表和会话状态，返回后执行必要的 fit，不重新创建进程。

### 3.5 Inspector

现有 Agent、Git、历史和通知右侧面板统一为 Inspector。宽窗口下可停靠，窄窗口下覆盖工作区；关闭时不保留空白网格列。原有快捷键和功能入口保持有效。

## 4. 洞察视图

洞察页是一张连续分析画布，不使用“每个数字一个悬浮卡片”的仪表盘模板。

### 4.1 顶部摘要

页面标题旁内联展示四项摘要：

- 命令总数
- 活跃天数
- 命令成功率
- 累计活动时长

摘要随项目与时间范围共同变化。累计活动时长为已结束命令块的 `endedAt - startedAt` 之和，不推断用户在线时长，也不把未结束记录计入时长。

### 4.2 活动热力图

热力图默认显示最近 365 个自然日，按本地时区归档。布局采用周为列、星期为行，显示月份和星期辅助标签。

每个日期格以命令数量分级：

- 0：无活动
- 1 级：大于 0 且不高于当前范围非零日期的 25% 分位数
- 2 级：高于 25%，不高于 50%
- 3 级：高于 50%，不高于 75%
- 4 级：高于 75%

分位数按当前筛选结果计算，使低频和高频用户都能获得可辨别的层级。悬停或键盘聚焦显示日期、命令数、成功数、失败数和活动时长。日期格可聚焦，方向键在相邻日期间移动。

在较窄窗口中保持单元格和间距稳定，热力图区域允许水平滚动，不把方格压缩为不可操作的色点。

### 4.3 活动趋势

趋势图支持 7 天、30 天、90 天和全年范围，按日汇总：

- 命令总数
- 成功命令数
- 失败命令数
- Agent 相关命令数

成功定义为 `exitCode === 0`。失败定义为存在且不等于 0 的退出码。没有退出码的记录计入命令总数，但不进入成功率分母。

第一版使用原生 SVG 或 CSS 绘制，不引入大型图表依赖。图表必须同时提供文字摘要和可聚焦数据点，不能只依赖曲线颜色传递信息。

### 4.4 项目排行

项目排行支持按命令量、活动时长和失败率排序。每行显示项目名称、主要数值、相对占比和最近活动时间。点击项目后保持洞察视图，并将全局筛选切换到该项目。

失败率仅在至少存在一个有退出码的命令时计算；没有可判定结果时显示“暂无结果”，不显示 0%。

### 4.5 Agent 分布

Agent 分布基于命令块所关联 pane 或 session 的 `agentKind` 汇总。普通 Shell 作为独立类别显示。每个 Agent 显示命令数、会话数和最近活动时间。

若旧命令块无法解析出 Agent 类型，则归入普通 Shell，不猜测类型。

### 4.6 最近活动

最近活动按时间倒序显示命令、项目、会话、结果、持续时间和发生时间。支持：

- 打开对应项目和会话
- 复制命令
- 在目标 pane 可用时重跑命令
- 收藏或取消收藏

列表采用紧凑行结构，不为每条记录创建独立卡片。

## 5. 数据架构

### 5.1 后端聚合

Rust 新增只读统计查询命令 `insights_summary`。命令参数包括：

- 可选 `projectId`
- `range`：`sevenDays | thirtyDays | ninetyDays | year`
- 可选客户端本地时区偏移分钟数

返回结构包含：

- 查询范围和生成时间
- 摘要指标
- 每日活动序列
- 项目排行
- Agent 分布
- 最近活动

命令由 `BlockStore` 的一致性快照聚合，不向前端暴露块文件路径，不增加通用文件权限。前端在 `shared/ipc/client.ts` 中提供唯一类型化包装，并在 `commands/mod.rs` 注册命令。

### 5.2 关联 Agent 类型

第一版优先从当前持久化 session 布局中的 pane 关联 `agentKind`。为了让历史数据在会话被删除后仍可准确统计，命令块模型新增可选 `agentKind` 字段，并通过 serde 默认值保持旧数据兼容。新命令块写入时记录该字段；旧记录继续按可关联信息归类。

### 5.3 时间与无效记录

- 日期聚合使用客户端传入的本地时区偏移，默认回退为 UTC。
- 范围起止在 Rust 中统一计算，前端不重复裁剪。
- `startedAt` 无法解析的记录从统计中跳过，并增加 `invalidRecordCount`。
- `endedAt` 早于 `startedAt` 时不计时长，但命令本身仍计数。
- 空数据返回完整的零值结构，不以错误表示。

### 5.4 刷新策略

洞察页首次进入和筛选变化时请求统计。收到 `blocks://updated` 事件后采用短暂防抖刷新。加载期间保留上一份结果并显示轻量刷新状态，避免整个页面闪空。

## 6. 视觉系统

### 6.1 设计方向

设计定位是高密度桌面开发工具，而不是营销页或消费级数据大屏：

- 布局变化度：6/10
- 动效强度：3/10
- 信息密度：7/10

页面采用非对称但严格对齐的网格。热力图占主要视觉宽度，趋势与排行形成次级节奏。页面区块主要依靠留白、细分隔线和标题层级组织，仅对真正独立的交互工具使用有边界容器。

### 6.2 色彩

- 应用底色：近黑炭色
- 一级表面：中性深灰
- 二级表面：略亮冷灰
- 主文本：冷白
- 次文本：中性灰
- 唯一主强调色：青绿色
- 成功、警告、错误：语义绿、琥珀和红

移除现有星空纹理、紫色渐变、装饰性辉光和多色像素闪烁。Agent 品牌色只在 Agent 身份标识的小范围内使用。

### 6.3 字体与形状

UI 继续使用 Windows 系统 UI 字体栈，终端和数字使用 Cascadia Mono / JetBrains Mono。字间距固定为 0。圆角体系限制为 2px、4px 和 6px，不使用胶囊式文字容器，分段控制除外。

### 6.4 动效

动效仅用于：

- 顶级视图切换的淡入和轻微位移
- Inspector 展开与关闭
- 热力图焦点和数据刷新反馈
- 按钮、菜单和选择状态反馈

所有动效在 `prefers-reduced-motion` 下关闭。不得添加循环背景动画、装饰粒子和无语义漂浮效果。

## 7. 响应式与窗口行为

目标平台仍为 Windows 桌面，但界面必须适应最小支持窗口：

- 宽度大于等于 1280px：上下文栏和 Inspector 可同时停靠。
- 900px 至 1279px：Inspector 以覆盖层打开，上下文栏可折叠。
- 小于 900px：主导航轨保留，上下文栏覆盖工作区；洞察页使用单列顺序，热力图横向滚动。

终端网格、工具栏、热力格、图标按钮和状态指示均使用稳定尺寸，动态文本不得推动相邻控件跳动。

## 8. 状态与错误处理

洞察视图必须实现：

- 首次加载骨架
- 后台刷新状态
- 无命令数据空状态
- 项目筛选后无数据状态
- 可恢复查询错误及重试按钮
- 只读模式提示
- 无效历史记录计数提示

统计失败只影响洞察视图，不能阻塞终端和其他模块。错误继续使用 `CmdError` 机器码与中文用户消息。

## 9. 可访问性

- 所有功能可通过键盘到达。
- 焦点环满足 WCAG AA 对比要求。
- 热力图单元格提供可访问名称和键盘导航。
- 图表同时提供文本摘要，状态不只依赖颜色。
- 所有图标按钮提供本地化工具提示与 `aria-label`。
- 在 200% UI 缩放下，文本不重叠，主要操作仍可见。

## 10. 测试与验收

### 10.1 Rust

- 聚合空数据。
- 7、30、90、365 天边界和跨年边界。
- 本地时区跨日归档。
- 成功率排除无退出码记录。
- 时长排除未结束和负时长记录。
- 分位数等级在低频、重复值和高频数据下稳定。
- 项目筛选、项目排行和 Agent 归类。
- 无效时间记录不导致命令失败。
- 旧命令块缺少 `agentKind` 时可正常反序列化。

### 10.2 TypeScript / React

- 顶级视图切换不注销终端实例。
- 时间范围和项目筛选传入正确 IPC 参数。
- 热力图日期、强度、提示和键盘导航正确。
- 加载、空、错误和后台刷新状态。
- 最近活动操作调用类型化 IPC 包装。

### 10.3 Playwright 与视觉验收

- 终端与洞察切换完整工作。
- 项目筛选、时间范围和最近活动跳转可用。
- 在 1440x900、1024x768 和 800x700 视口截图检查。
- 无文字遮挡、按钮溢出、网格变形和无意义空白。
- 热力图非空且颜色等级可辨；空数据画面同样完整。
- 键盘可完成导航、筛选和返回终端。

## 11. 明确不做

- 不采集键盘内容、遥测或应用外活动。
- 不将 Agent 历史文件写回或修改。
- 不推断“生产力评分”或生成带价值判断的排名。
- 不引入远程统计服务。
- 不在第一版实现自定义报表、数据导出或跨设备同步。
- 不改变 PTY 生命周期、输出批处理和重放协议。

## 12. 完成定义

只有同时满足以下条件，本次重设计才算完成：

1. 新信息架构在真实应用中可用，终端核心工作流无回归。
2. 洞察视图展示真实热力图、摘要、趋势、项目排行、Agent 分布和最近活动。
3. 统计聚合由 Rust 后端完成并具备覆盖边界条件的测试。
4. 前端视觉系统已替换旧的星空紫色装饰语言，并通过三种目标视口的截图检查。
5. TypeScript、Vitest、Vite 构建、Rust 测试和 UI Playwright 测试通过。
